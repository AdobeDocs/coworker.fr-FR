# Événements de collaborateur d’audit {#audit}

Découvrez comment auditer les événements dans Adobe CX Enterprise Coworker. L’audit permet aux administrateurs d’enregistrer les actions entreprises par Coworker dans l’ensemble de leur organisation.

>[!NOTE]
>
>Votre organisation doit être activée pour que vos collègues puissent utiliser cette fonctionnalité. L’audit sera disponible progressivement et peut ne pas être activé pour toutes les organisations de collaborateurs au lancement.
